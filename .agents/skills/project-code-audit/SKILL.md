# Project Code Audit

Read the repository AGENTS.md and docs/review/code-audit-guidelines.md first. Inspect the current Git diff and relevant contracts, schemas, platform branches, tests, and documentation.

Route shared findings to the Linux Cross-platform Owner, Windows-specific findings to the Windows Platform Owner, and uncertain boundaries as NEEDS_VERIFICATION. Distinguish implementation evidence from validation evidence. Report severity, location, evidence, owner, recommended action, and required validation. Do not infer native GUI, real integration, installer, signing, or external-service acceptance from mocks, startup, or smoke tests.
