## 未随迁移改变的事实

- Seven-asset era whose Extension asset is a real ZIP; the target series ships every archive as a real 7z container, so the package is extracted and re-archived with identical contents.
- The frozen Extension ZIP contains only manifest.json and src/; this era predates the popup/options files. Migration preserves that payload unchanged and does not repair it.
- The dependency/Full archives embed a package-manifest.json naming this tag and a Native Host manifest whose path is the CI runner directory; tag and placeholder metadata are regenerated.
- No Windows WDIO or GUI acceptance was recorded against this version.
- 迁移不改写历史 tag、历史 run 与历史验证记录；也不把任何历史 FAIL/NOT_RUN 改写为 PASS。
