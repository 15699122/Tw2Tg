## 未随迁移改变的事实

- The two assets published on the old Release were built from commit 97959fa974b32f3a357a0d80682e6aefefa8533e, not from this tag; they are frozen as evidence and never reused.
- The exact-tag historical Windows run 35567742785 failed Native Host configuration before packaging.
- Source material is the isolated verified package set of run 36655693790 (artifact legacy-pre6-source-build-36655693790, expires 2026-12-29); its executable SHA-256 is pinned in this ledger and verified before reuse.
- That isolated package set already drops extension test files and replaces the runner-local Native Host path with the installation placeholder, so this version is re-issued with the corrected packaging rather than the polluted payload.
- Installing the Native Host on a target machine is still unverified.
- 迁移不改写历史 tag、历史 run 与历史验证记录；也不把任何历史 FAIL/NOT_RUN 改写为 PASS。
