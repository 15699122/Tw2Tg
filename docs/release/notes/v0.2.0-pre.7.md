# XArchive v0.2.0-pre.7

> Browser Extension identity 与 Windows release packaging 前置修复预发布版本。本版本用于开发和验证，不是稳定生产版本。Windows Named Pipe、Native Host Registry、真实 Edge/Chrome 集成和完整 Windows runtime 验收仍需单独验证。

## 版本摘要

本版本在 `v0.2.0-pre.6` 的 Browser Extension hardening 基础上，固定 Extension public identity，收紧 Native Host manifest contract，并修复 Windows release workflow 的 source/tag parity 和发布资产一致性边界。

## 主要更新

### Extension identity

- `extension/manifest.json` 固定 public `key`；
- canonical development/self-hosted Extension ID 为：

  ```text
  iaajefkoanbkleojofoadeakelihbjne
  ```

- package 前自动检查 manifest public key 与 `XARCHIVE_EXTENSION_ID` 一致；
- Extension ID 校验收紧为 Chromium `a-p` 字母表的 32 个字符；
- Native Host `allowed_origins` 由已验证 identity 生成。

### Windows release workflow

- `workflow_dispatch` 显式 checkout 指定 `release_tag`；
- 增加 tag、checked-out HEAD 和 workflow SHA parity 检查；
- 支持 Repository Variable `XARCHIVE_EXTENSION_ID`，并保留 Secret fallback；
- Native Host manifest 统一由 repository script 生成，不再由 workflow 重复手写；
- 上传前生成并校验五资产 release manifest 与 `SHA256SUMS`。

### Packaging

- 增加独立 Extension ZIP；
- 校验 Extension ZIP required files 和排除项；
- 生成 JSON release manifest，记录 source SHA、asset hash、size、Extension ID 和 license metadata；
- package contract 拒绝 private key、SOPS secret、cache、tests 和其他开发文件。

## Linux 验证

当前 source revision 已通过：

```text
cargo fmt --all -- --check
cargo check --workspace
cargo test --workspace --no-fail-fast
npm run check
npm run test --workspace desktop       # 62/62
npm run check --workspace extension
npm run test --workspace extension     # 21/21
python -m pytest sidecar/tests -q      # 21 passed
```

这些结果是 Linux/source-level 证据，不能替代 Windows Edge/Chrome、Named Pipe、Registry、WebView2、真实浏览器和最终 Windows artifact 验证。

## Windows 状态与限制

以下项目仍为 `WINDOWS_VERIFICATION_PENDING`：

- Chrome/Edge developer-mode Extension ID 实测；
- Full package 中 Native Host manifest 与实际解压路径；
- Windows Sidecar v2 handshake 稳定性；
- Windows Named Pipe Desktop transport；
- HKCU Native Messaging Host Registry install/repair/unregister；
- Browser Service Worker reload、Native Host reconnect 和真实 `query_status`/`archive_request`；
- 五类 Windows release asset、license/source parity 和 SHA256SUMS 的真实 runner 结果。

本版本不声明 installer、updater、Tray、Autostart、Credential Manager 或真实浏览器到 Desktop 的生产链路完成。

## 发布源代码

- 预发布 tag：`v0.2.0-pre.7`；
- Release source 必须是该 tag 对应的 commit；
- Windows workflow 必须通过 source/tag parity gate 后才能上传资产；
- `v0.2.0-pre.5` 和 `v0.2.0-pre.6` 不作为本版本的资产来源。
