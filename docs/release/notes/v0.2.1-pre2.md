## 3. 本版本变更（相对 `v0.2.1-pre1` `3115c3b`）

### 3.1 Desktop UI 一致性与视觉打磨（Round-2 + M1–M3）

- **工作台与任务记录**：
  - 统一「工作台 → 最近任务」与「任务记录」空状态为居中 `1px` 虚线图标框（`EmptyState`）；缩短「运行环境」底部说明避免孤立换行；
  - 指标卡零值回归 `#171717`（`metric-default`），非零完成/失败状态接入 `--success`（`metric-green`）/ `--danger`（`metric-red`）语义色；`.dashboard-detail` 启用 `text-wrap: pretty`。
- **下载配置**：
  - 补齐「输出与配置」分组标题与 `10px` 卡片外框，使上下结构对称；开关开启态统一品牌森林绿 `#2e6f59`，补齐下拉框与开关行间距（`20px`）以及开关行与说明段落间距（`.batch-form-options + .settings-help` `12px`）；
  - 只读 `gallery-dl` JSON 参数框改用 `--surface-muted`（`#f4f4f4` 浅灰底）与 `resize: none` 隐藏缩放柄；
  - 错误提示升级为 `--danger-surface` 柔化红底、`1px solid #f0b8b5`、`7px` 圆角、`9px 11px` 内边距提示条（`margin-top: 12px`，与下方动作按钮保持 `14px` 间距）；
  - `aria2` 状态行与 SHA-256 说明中的 `aria2c` 统一为等宽 `<code>` 标签；未检测到 `aria2` 时，「当前生效的 aria2 可执行文件」展示条采用 `1px` 边框 `--surface-subtle` 圆角路径槽容器（`.path-display`）。
- **账号归档、存储、记录导入与设置**：
  - 「账号归档」底部空状态统一为居中 `EmptyState` 组件；「存储」页单卡片移除折叠箭头与折叠交互（`.settings-panel-static`）；
  - 「记录导入」补齐 `10px` 卡片、表格预览徽章与等宽根路径；
  - 「设置」页 Telegram 凭据与代理诊断 URL 输入框统一满宽（`max-width: none`），中文说明与 3 列诊断网格对齐；全局禁用按钮统一为 `1px` `--border` + `--surface-muted` + `opacity: 1`；焦点轮廓 `--focus-ring` 保持平台蓝 `#0067c0` / `#78baff`；`html { overflow: hidden }` 与 `.main-panel { overflow-y: auto }` 消除双滚动条。

### 3.2 Windows 原生执行、文件系统与崩溃恢复（W1–W7）

- **W1 写入隔离与后代进程排空**：新增 `crates/xarchive-win-job-iocp` 安全 IOCP 包装，升级 `WindowsWriterJob::stop_and_drain` 验证 `JOB_OBJECT_MSG_ACTIVE_PROCESS_ZERO` 与后代进程排空，接入 `ProductionExecutionFactory` 与 `Aria2Supervisor::spawn_windows_contained_owned`。
- **W2 文件系统语义**：修复 1:1 `$UpCase` Unicode 折叠、缺失父目录 junction 锁拆分及 8.3 短名竞争。
- **W3 配置交换与执行器维护排空**：验证预览绑定、配置替换失败回滚与真实 contained-writer 维护排空（`windows_config_apply_e2e`）。
- **W4 / W5 输出与崩溃恢复**：验证 D1 四种 JSON/YAML 导出组合、`>260` 字符长路径发布及 Windows `InternalV1` 启动崩溃恢复。
- **W6 浏览器配对、aria2 与离线包**：完成真实 Microsoft Edge `159.0.4402.13` `legacy -> automatic` Native Host 配对迁移与失败保留测试（切换至 EdgeDriver `159` / `157`，移除过期 `153`）；完成真实 `aria2c.exe` 403 刷新下载与 6 组件 Offline Bundle 装配及 WebView2 启动验证。
- **W7 传输切换焦点与并发稳健性**：新增并验证 `transfer-switch-focus`、`transfer-switch-held-busy` 与 `transfer-switch-moved-focus` 专项 E2E。

### 3.3 跨平台内核、模块化重构与 CI 门禁修复

- **运行期授权与崩溃恢复（B3–B5 / P2 / L1）**：`PendingArchivePublication` 仅在 verified attempt facts 产生后由 live session finalize；未消费即 `Drop` 时保持惰性不写 journal 并释放准入；`v1_publish_crash_windows_converge_through_production_prepared_replay` 覆盖 prepared / rename / directory / committed 四窗口崩溃重放。
- **D1 归档元数据导出与 F2/F3 配置/记录交换**：支持 `tweet.json` / `tweet.yaml` 冻结选择导出与无替换发布语义；F2 新增 `cancel_configuration_exchange` 与 `exchange_apply_wait` 区分取消、超时与真实 I/O 失败；F3 补齐记录导入/导出边界校验。
- **模块化架构门禁（P0–P13）**：完成核心 crate 与桌面端模块边界拆分，启用 `scripts/check-architecture.mjs` 基线门禁。
- **Linux CI 与测试稳健性修复**：为 `pre-release.yml` 补充 `xarchive-lock-probe`（`--features __lock_probe`）前置构建；修复 `command_line.rs` mock `aria2` 写 `argv.json` 的并发竞态、`ui-wiring.test.mjs` 未闭合测试块以及全工作区 `clippy --all-targets -D warnings` 告警。
