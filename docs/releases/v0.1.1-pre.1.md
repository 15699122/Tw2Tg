# XArchive v0.1.1-pre.1

## 更新内容

- 改进 Sidecar v1 的下载任务控制与错误分类。
- 区分用户取消与应用关闭导致的任务中断。
- 改进下载任务状态持久化与任务恢复相关处理。
- 优化设置页和基础下载配置流程。

## 已知问题

- 取消正在运行的任务时，部分环境可能仍需要等待子进程退出。
- 个别视频或受限媒体 URL 可能下载失败。
- 部分设置项的运行时反馈仍不够及时。
