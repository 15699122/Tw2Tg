# XArchive v0.1.1-pre.3

## 更新内容

- 优化 Desktop GUI 的布局与任务信息展示。
- 增加任务统计相关界面与状态展示。
- 完善 portable worker 的打包与运行契约。
- 改进下载组件、桌面端和 Extension 之间的状态反馈。

## 已知问题

- 大量历史任务可能增加统计页面的加载时间。
- portable worker 在部分 Windows 环境中可能受到路径或权限设置影响。
- 外部组件未正确安装或路径不可访问时，相关功能无法正常运行。
