# XArchive v0.2.0-pre.15（发布资产与独立 WDIO 演练）

> 本版本用于演练 Windows 发布链路，不代表 Windows GUI 或实际归档功能已验收。按现状提供，仅供个人使用；不保证跨设备可用或真实 X 帖子归档成功。

## 发布门禁与验证范围

- Linux Pre-Release workflow 从本说明所在的精确提交执行 Linux 检查，创建 `v0.2.0-pre.15` tag 和预发布，并派发该 tag 的 Windows Release Build。
- Windows 构建仍须校验 tag/source、五个非空资产、release manifest 和 SHA256SUMS；任何资产缺失或哈希不一致均阻断上传。
- 独立 Windows WDIO job 下载**同次构建 run** 的 `.exe` 与身份 artifact，核对 run ID、source SHA 和 `.exe` SHA-256 后执行 preflight 和 dashboard WDIO。其 FAIL/BLOCKED 不单独阻断合法资产发布，但不能记为 PASS，也不能宣称 GUI 验收。
- 演练后逐次记录 Linux 与 Windows run ID、source SHA、`.exe` SHA-256、Release 资产链接、WDIO 真实状态和诊断 artifact；未执行时记 NOT_RUN，Windows Owner 另行完成 GUI 与打包验收。
