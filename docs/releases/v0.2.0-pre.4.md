# XArchive v0.2.0-pre.4

> 基于当前 `feature/u7-desktop-production-integration` 分支提交构建的 Windows x64 预发布版本。本版本用于 Windows runner 构建、资产组装和发布流程验证，不是稳定生产版本。

## 主要更新

- 保留 U8 之后的 Sidecar protocol v2、extraction-only 和 aria2-only 目标边界。
- 完成 U12 Native Host/Extension 安装契约和显式 Extension 状态区分。
- 完成 U13 Offline Bundle 组件、路径、hash、size、license 和 catalog parity 契约。
- 完成 Linux 端 U14 适用验证，并基于最新 Windows 验证结果更新状态和验证队列。
- Windows runner 验证当前 source 的 Rust、Node、Sidecar、Tauri、worker、Core/Full portable 和 WDIO 构建范围。

## 发布源代码

- 源代码分支：`feature/u7-desktop-production-integration`
- 构建源代码：以本 Release 对应 tag 指向的提交为准
- 目标平台：Windows x64
- 发布类型：预发布版本，用于构建和集成验证

## 发布资产

| 资产 | 说明 |
|---|---|
| `XArchive-v0.2.0-pre.4-windows-x64.exe` | Windows x64 Desktop 单文件可执行程序 |
| `XArchive-v0.2.0-pre.4-windows-x64.7z` | 仅包含 Desktop 单文件可执行程序的 7z 压缩包 |
| `XArchive-v0.2.0-pre.4-windows-x64-repository-dependencies.7z` | 本仓库 Extension、XArchive worker、manifest 和许可证/声明 |
| `XArchive-v0.2.0-pre.4-windows-x64-full.7z` | Desktop、Extension、XArchive worker、gallery-dl、aria2、manifest 和许可证/声明 |

实际资产的文件名、大小、SHA-256、上传状态和内容必须以本 Release 页面及对应 Windows workflow 为准。

## 当前验证边界

- Windows runner 已验证 Rust workspace、Node workspace、Sidecar、v2 worker、Tauri executable、Core/Full portable assembly、startup smoke 和当前 WDIO scope。
- U7 真实 aria2/extraction/refresh/commit/recovery、U9/U10 filesystem/activation、U12 Registry/browser/Native Host reconnect、U13 final Offline Bundle parity/signature/license scan 仍需单独验证。
- 不得把本地构建、startup smoke 或 WDIO PASS 外推为真实账号、浏览器、Registry、Named Pipe、文件系统 recovery 或完整 Offline Bundle PASS。
- 当前发布资产不包含预创建的 `config/`、`cache/`、`download/` 或 `logs/` 运行时目录。
