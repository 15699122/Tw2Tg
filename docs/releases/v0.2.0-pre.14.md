# XArchive v0.2.0-pre.14（发布链路演练）

> **这是一个预发布演练版本，不是可用性发布。** 本次演练用于验证 Windows 发布就绪门的直连 msedgedriver capability 修复。`v0.2.0-pre.13` 在 Windows 就绪门因直连模式仍发送非法顶层 `webviewOptions` 而失败；本版本移除该 capability，改为仅发送 `browserName: webview2` 与 `ms:edgeOptions.binary`。

## 使用范围与限制

- 本项目用于**个人用途**，按现状提供；**不保证在其他设备、账号、网络或浏览器配置下可用**。
- **不承诺真实 X 帖子归档成功。** 真实归档依赖 X 的登录状态、页面结构、限流和网络环境。
- 本演练的资产（如产生）只用于核对发布流程、资产命名、7z 格式、哈希与 release manifest，不代表 Windows 功能、兼容性或人工验收通过。

## 本轮变更

- 修复直连 msedgedriver 模式向 WebDriver 发送非法顶层 `webviewOptions` capability；
- 保留 tauri-service 模式的既有 `webviewOptions` 配置；
- 增加/更新配置回归测试和 Windows WDIO 交接说明；
- Linux 定向回归测试已通过：35/35。

## 发布源码与验证边界

- 预发布 tag：`v0.2.0-pre.14`，应由 `Linux Pre-Release` workflow 在 `release/v0.2.0` 的提交 `59c41d6` 上创建；
- Windows workflow 必须验证 tag 与 checked-out source parity 后才允许上传资产；
- Windows 本机验证队列仍保持 `PENDING`，不得将 hosted-runner readiness gate 成功扩大为完整 Windows 验收；
- 若演练失败或没有资产，应保留 workflow run 与诊断 artifact，并将该版本标记为不可用，不向 tag 补传未经验证的资产。
