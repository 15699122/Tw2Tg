# XArchive v0.1.1-pre.2

## 更新内容

- 优化设置页交互，增加路径复制功能。
- 增加 aria2 路径配置与版本检查相关设置。
- 增加 Extension 状态展示与管理入口。
- 改进桌面端与下载组件之间的状态反馈。

## 已知问题

- aria2 自定义路径在部分环境中可能需要重新启动应用后生效。
- Extension 状态刷新可能存在延迟。
- 不同 Windows 权限环境下，外部组件路径检查结果可能不同。
