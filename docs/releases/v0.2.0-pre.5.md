# XArchive v0.2.0-pre.5

> Windows x64 预发布版本，用于 Desktop UI、Extension 状态、Native Messaging 打包和集成契约验证。本版本不是稳定生产版本。部分 Windows 运行时和浏览器集成项目仍处于待验证或阻塞状态。

## 主要更新

### Desktop UI 与路径交互

- 合并首次使用时的下载目录说明，调整 Dashboard、Settings、侧栏和服务状态布局；
- 修复 Browser/Globe SVG 图标路径；
- 统一归档目录、日志目录、aria2、gallery-dl 和 Extension 路径的可复制控件；
- 保留完整路径的 `title` 信息，并将复制反馈限制在对应控件内；
- 继续通过 Tauri clipboard boundary 处理复制操作。

### Extension 状态

- 区分刷新/检测过程和最终 Extension 状态；
- 不再将 `not_loaded` 永久显示为“检测中…”；
- 显式区分文件缺失、Native Host 未注册、浏览器未连接、已连接、检测失败和刷新中；
- Settings 增加 Extension 局部刷新操作。

### NativeBridge 与 Native Host 打包

- 统一处理同步 `connectNative`、`postMessage` 和 `chrome.runtime.lastError` 错误；
- Native Host 断开时拒绝 pending requests，并清理失效 port；
- Full portable 包包含 Native Host executable 和 host manifest 边界；
- Full 包组装要求 `XARCHIVE_EXTENSION_ID`；
- Host manifest 校验 Extension ID 并生成 `allowed_origins`；
- Core 包不包含 Extension、Native Host 或其他浏览器组件。

## 验证状态

Linux 侧完成了相关 Node、Extension、Rust、Native Host、打包契约和 `git diff --check` 验证。当前准确数量和后续增量结果以 `docs/development/status.md`、`docs/development/testing.md` 为准。

Windows 状态必须按以下边界理解：

| 项目 | 状态 | 说明 |
|---|---|---|
| Ordinary/Advanced native WDIO | `WINDOWS_FAIL` | 历史 WebView2/tauri-driver native session 未形成当前 UI 通过证据。 |
| Registry/ACL | `WINDOWS_BLOCKED` | 当前用户 Native Messaging Host 注册、修复和取消注册未执行。 |
| Edge/Chrome 集成 | `WINDOWS_BLOCKED` | 真实 developer-mode Extension 加载和 browser profile 验证未完成。 |
| Named Pipe/reconnect | `WINDOWS_BLOCKED` | Windows Desktop Named Pipe server 和真实 reconnect 链路未完成。 |
| 当前 source 的 Release workflow | `NOT RUN` | 历史 workflow 只适用于对应 tag/source。 |
| 最终资产 hash/license/parity | `NOT RUN` | 当前 source 没有被接受的最终资产集合。 |
| Offline Bundle/signature/parity | `NOT RUN` / `WINDOWS_BLOCKED` | 未执行最终签名 bundle 验证。 |

完整证据和手工步骤见 `docs/development/windows-validation.md` 与 `docs/validation/windows-queue.md`。Linux PASS 不得外推为 Windows PASS。

## 已知限制

本版本不证明以下能力已经完成：Edge/Chrome Native Messaging 注册、Windows Named Pipe Desktop transport、真实浏览器 `query_status`/`archive_request`、真实 X 认证和媒体归档、Windows filesystem recovery/reparse/ACL/long-path、installer/updater/Tray/Autostart/Credential Manager、signed Offline Bundle 和最终 Release asset parity。
