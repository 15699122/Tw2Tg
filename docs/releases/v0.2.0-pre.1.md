# XArchive v0.2.0-pre.1

## 更新内容

- 改进 Sidecar 的取消、关闭和子进程生命周期管理。
- 新增 Sidecar protocol v2 的 typed command/event contract。
- 将 gallery-dl extraction-only 适配层与媒体传输职责分离。
- 新增 aria2-only transfer driver，支持多媒体传输、进度、取消、超时和临时文件清理。
- 新增过期或被拒媒体 URL 的一次性 refresh contract，并在刷新结果发生媒体身份变化时拒绝静默覆盖。
- 改进媒体身份、文件名和请求头的安全校验。

## 已知问题

- 本版本的新 protocol、transfer driver 和 URL refresh contract 尚未接入完整的 Desktop 生产归档链路。
- 旧版 Sidecar download 与兼容路径仍处于迁移阶段。
- 受限媒体、过期签名 URL、浏览器 Cookie 和外部组件配置可能导致归档失败。
- Windows 进程树、文件锁和打包运行环境可能受到本机权限与安全软件影响。
