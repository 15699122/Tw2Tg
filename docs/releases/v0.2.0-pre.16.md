> 仅用于验证修复后的发布流程和资产，不代表 Windows GUI 或真实 X 归档已验收。仅供个人使用，按现状提供，不保证跨设备可用。

## 变更及前次失败

`pre.15` 的 Windows 构建在 Rust 测试 `batch::tests::persists_each_discovery_candidate_before_completion` 失败，未产出 exe、Release 资产或 WDIO 结果。本版用测试专用确认握手取代依赖 Windows 调度速度的固定 Python `sleep(0.5)`：观察线程确认候选项已经持久化、batch 仍为 `RUNNING` 后，stub 才发送完成事件。生产发现与持久化逻辑不变。
