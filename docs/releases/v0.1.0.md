# XArchive v0.1.0

## 更新内容

- 提供 Windows 桌面应用，用于归档 X/Twitter 推文及其媒体内容。
- 支持视频与多图媒体归档，并提供任务进度查看、暂停和取消操作。
- 使用 Sidecar worker 执行媒体下载，并使用 SQLite 保存任务状态。
- 提供桌面端、Sidecar 与 Native Host 的基础运行链路。

## 已知问题

- 当前版本仅提供 Windows x64 发布资产。
- 部分媒体或文件名边界情况仍可能需要人工处理。
- 首次运行时需要根据本机环境配置必要的运行组件。
